# 익형 설계 탐색기 (Streamlit)

정보 과제 연구 "익형 형상 데이터 기반 공력 대리모델과 역설계"의 결과를 직접 조작해 볼 수 있는 웹 도구입니다.

## 폴더 구성
```
app.py              웹 도구 코드
requirements.txt    필요한 패키지
data/               Colab의 내보내기 칸으로 만든 데이터 (6개 파일)
```

## 기능
1. 형상 분석: NACA 4자리 형상(두께·캠버·캠버 위치) 또는 UIUC 실제 익형을 골라 CL, L/D 곡선 예측. 학습 데이터에 XFOIL 값이 있으면 함께 표시
2. 강성–효율 지도: XFOIL로 직접 계산한 325개 형상의 파레토 전선, 이전 PINN 최적점, 현재 형상
3. 역설계: 최소 강성 조건 → XFOIL로 검증된 최고 형상 + 대리모델 유전 알고리즘 후보(검증 안 됨)
4. 탐구 요약
